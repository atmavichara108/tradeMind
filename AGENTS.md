# TradingMind — агентские инструкции

## Статус: изолированный проект

Этот вольт **не входит** (пока) в экосистему Корабля. Практически это значит:

- нет регистрации в реестрах Корабля (отсеков, ведомств, решений, почты);
- нет связи с ЦУ/ИЦ/УАС, ТСУ и общей памятью волта Корабля;
- источник правды по проекту — **этот вольт**: его заметки, `09_Meta`,
  `02_Mentor`, `AGENTS.md`;
- всё созданное здесь остаётся здесь; подключение к экосистеме — только по
  прямому слову владельца.

## Правило №0 — человеческий язык

Любая формулировка «решение за тобой», «ждёт твоего решения» обязана сразу
расшифровываться: что за вопрос по сути, какие варианты, что нужно от
владельца и что будет после его слова. Незнакомый термин — первой строкой.
Длинное — в файл, в чат — резюме.

- каждая заметка — с frontmatter YAML (источник для Dataview);
- связи — wikilinks `[[...]]`; теги — только из таксономии `03_Glossary`;
- шаблоны — из `09_Meta/Templates`.
