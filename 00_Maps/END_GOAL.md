# Конечная цель TradingMind (как её видит СерО)

## Одна фраза
**Второй мозг, который понимает разметку наставника лучше среднего участника чата — и доводит понимание до живого исполнения: Maya воспроизводит разметку на реальных чартах, наставник признаёт ученика; решения транслируются в торговую систему друга без потери сути.**

## Четыре слоя цели (каждый — со шкалой 0..1)

### L1. Понимание (мозг знает)
- π-словарь закрыт: все доли (0,157 / 0,314 / 0,4669 / 0,618 / 0,648 / 0,75 / 1 / 1,5 / 2 / 3,14 / 6,28) с описанием «когда какая ветка применяется»
- словарь разметки (цвета, круги, зоны, стрелки, наклонная сетка, гармошка) покрывает 90% чартов архива без «непонятных элементов»
- mastery: unclear в глоссарии → ноль (остаются только честные «?» наставнику, ≤5 шт.)
- **мера:** чарты наставника, которых я ещё не видел, описываю заранее (до чтения его текста) с верным направлением сценария

### L2. Воспроизведение (Maya умеет)
- Maya в replay сама ставит якоря и сетку; расхождение с наставником по якорям ≤ 0,5%, по ступеням ≤ 0,1%
- ≥ 10 кругов практики с моей числовой сверкой (публичные API Bybit/Binance)
- наставник хотя бы раз отвечает на разметку Maya как на «свою» (принимает игру), а не как на новичковую
- **мера:** скрины в practice/ с зелёными сверками + реакции наставника в архиве

### L3. Собственное мнение (мозг предлагает)
- ≥ 5 сетапов доведены до status: active с чек-листом вход/стоп/цель/отмена
- бэктест-скелет TradingMind гоняет правила «отсечка+синенькая», «гармошка», «половинку прикрыл» на исторических свечах
- **мера:** цифры win-rate/матожидания по каждой механике, а не только текст

### L4. Трансляция (система друга ест мозг)
- экспорт мозга в машиночитаемом виде (JSON: термины, сетапы, π-уровни, правила P0–P3, стоп-протоколы)
- агентская система друга consumes формат и торгует/бэктестит по нему
- **мера:** живой пайплайн vault → JSON → чужой агент, без ручной перетасовки

## Kill-критерии (цель уходит в сторону)
- наставник дважды скажет «ученик повторяет схему, но не понимает»
- Maya потеряет интерес к практике (его слово)
- друг не возьмёт формат экспорта после двух итераций
