# Языковая разморозка

## Цель
Усвоить язык наставника пассивно через повтор и связи.

## Протокол
При каждом новом сообщении/блоке от наставника:
1. Скопировать в 02_Mentor/Transcripts/YYYY-MM-DD.md
2. Прочитать вслух один раз
3. Подчеркнуть незнакомые термины → в 03_Glossary как заглушки
4. Подчеркнуть метафоры (мандельброт, вибрация, загогулина) → в отдельный файл 09_Meta/Mentor_Metaphors.md
5. Не пытаться понять всё. Двигаться дальше.
