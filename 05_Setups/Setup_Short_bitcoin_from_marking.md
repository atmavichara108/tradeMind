# Шорт битка с отсечки с усреднением

## Условия входа
- Цена находится на отмеченной наставником отсечке
- Первая часть позиции открывается шортом

## Позиция
- Первый объём: половина [[Рабочий лот]]
- Второй объём: заходит в усреднение на касании заданной линии [[Каскад усреднений]]

## Стоп
- Выше линии усреднения ставится стоп
- При срыве выше позиция закрывается

## Сопровождение
- При движении в прибыль часть закрывается
- При закрытии половины половины включается режим «сейф»
