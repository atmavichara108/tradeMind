# Критика стандартного ТА наставником

Из [[2026-05-01]]:

- «что 50 по фибо выдали это обычное дело для любых откатов»
- «и фиба стандартная, значения то не поменял»
- «и отображает она в данном случае лишь то, как внутри нее распределены пропорции импульса»
- «почему и говорю, 95% всего теханализного мусора по рынку — на помойку»

## Вывод для модели
Стандартные Фибо-уровни нужно перестать считать сигналом. Они могут использоваться только как описание пропорций импульса внутри авторской сетки.
