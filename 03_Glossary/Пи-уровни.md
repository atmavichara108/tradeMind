# Пи-уровни

## Суть
У наставника на сетке встречаются доли, совпадающие с десятичными приближениями π:
- `0.157` = π/20
- `0.314` = π/10
- `0.471` = 3π/20
- `0.628` = π/5
- `0.785` = π/4

Это не стандартный набор Фибоначчи и не стандартный Fib-ретейсмент из TradingView.

## Зачем нужны
Используются как доли измеряемого хода рядом с `0`, `0.25`, `0.5`, `0.618/0.648`, `0.75`, `1`.
