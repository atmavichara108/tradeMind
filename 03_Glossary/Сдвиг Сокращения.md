# Сдвиг Сокращения / Сдвиг Расширения

## Кратко (гипотеза)
Механизм поправки проекции «этажа» (целевой зоны). Цена проломила полку; насколько она вернулась **обратно за точку пробоя** — настолько проекция этажа сдвигается:
- **Сокращение** — стрелки внутрь этажа, цель притягивается к пролому (USDRUB 30.03 09:24);
- **Расширение** — стрелки наружу этажа, цель уезжает за границу (тот же кадр 09:27, «иногда бывает обратная ситуация, когда работает сдвиг Расширения... по тем же принципам»).
