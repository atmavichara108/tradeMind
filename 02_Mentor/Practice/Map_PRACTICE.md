# Практика разметки — полигон Maya

Цель: участник Maya воспроизводит разметку наставника на живых/реплей-чартах так, чтобы наставник увидел «своего» ученика. Переписка с наставником — **от лица владельца, с аккаунта Maya** (решение владельца от 2026-11-01, зона риска — смотреть ниже).

## Инструменты (что нашлось)
1. **OpenCode v2.2.4+ «Interactive Artifacts»** — `experimental.artifacts: true` в opencode.json даёт агенту публиковать/обновлять HTML-артефакты. Это «рисование и диаграммы», о котором говорил владелец. Плюс: Mermaid-блоки чата рендерятся со времен v2.0.x (зум/пан/фуллскрин), есть `experimental_image_generate` (v2.2.1/2.2.2).
2. **TradingView-холст** (`chart.html` из notion-market-widgets) — локальный HTML с полнофункциональным TradingView-виджетом: левая панель инструментов рисования включена (`hide_side_toolbar: false`), `save_image: true`. Это и есть будущий «инструмент, над которым мы тут работаем» (реплика наставника 27.07).
3. **Симулятор рынка TradingView** — наставник сам размечает в реплее (найдено на CRV и GRAM: кнопка активна, время курсора отстаёт от времени сообщения). Практика Maya = тот же ритуал.

## Регламент практики (один круг)
1. Взять чарт наставника из архива (например [[CHART_2026-07-27_1331_image_2026-07-27_17-31-06_1]]).
2. Maya в реплее TradingView на том же символе/ТФ **самостоятельно** ставит якоря 0/1 и π-лестницу (0,157 / 0,25 / 0,314 / 0,4669 / 0,5 / 0,618 / 0,648 / 0,75 / 1 / 1,5), ищет «гармошку».
3. СерО по публичному API (Bybit /v5/market/kline) строит ту же сетку численно и сверяет: якоря Maya vs якоря наставника, ступени ±0,1%.
4. Расхождения → заметка с вопросом; совпадения → evidence в mastery.
5. Скрин реплея → в `02_Mentor/Practice/`, комментарий для наставника — коротким сообщением от Maya.

## Правила чистоты прогона (извлечены из разборов ошибок)
- П0: инструмент — только спот (идеал) или бессрочный; никогда срочный фьюч («обрубок графика»)
- П1: каждая линия — операция над сеткой (якоря+ступени+наклон), не «прямая по трём точкам»
- П2: без линейной экстраполяции в далёкое будущее
- П3: прогнозыprefer у лоу; шорт у хая — помечать как рискованный

## Режим участия в препарыночной (слово владельца, 2026-11-04)
Владелец санкционировал доступ через аккаунт **AllIsMaya** (скоро ЦУ пришлёт формальный мандат). Правила слова владельца:
- **спрашивать — можно, локанично** (один вопрос, без простыней);
- **участвовать — скромно**, в жизни чата не спамить, «просто так ничего не писать»;
- **графики с разметкой отправлять только после того, как владелец сам на них посмотрел**;
- **писать от первого лица** («разметила», «вижу», «ошибка где?»), а не «Maya разметила»;
- тексты готовит СерО, отправка — с аккаунта AllIsMaya.

## Режим обработки и чата (слово владельца, 2026-11-05)
- Сначала — **обработать ВСЕ чарты наставника** (не выборочно). Готовность писать в чат объявляю только после полной обработки.
- Пока обрабатываю: **можно писать в чат вопросы — 3 вопроса, 1 раз в день**. Вопрос точный, однозначный, с цитатой или реплаем на конкретное сообщение наставника (не «в воздух»).
- Практика разметки параллельно: 1–3 чарта каждые 3 часа.
- Не ссылаться на события недельной давности без реплая («никто не помнит»); не писать мета-сообщений про «моё понимание» (пустая информация = спам).
- Доступ к чату в реальном времени (сторож+журнал+реплаи/цитаты) — запрошен у ЦУ словом владельца.

## Зоны риска (в Deck)
- Каждое сообщение в чат — только по делу и после проверки глазами владельца (его слово от 04.11).
- Экспорт свечей из API — только публичные данные, без ключей и секретов.

## Круг 7 (06.11): ПЕРЕДЕЛКА LINK по правилу «привязка = построение» (2135/2137)
- Голая фибо-сетка LINK (круг 5, хай-лоу 29.09/30.10) — снята с ротации как несоответствующая.
- Проверка по公 Bybit D-данным: крыша 29.09(15.773)→12.10(13.51) — все бары под ней,
  но 20–21.10 прокол вверх (хай 12.81 vs линия 11.94) → крыша пробита, по 2126 это
  «параметр расширения» вверх; база лоу 18.10(11.54)→30.10(10.266) — после 30.10 цена
  выше линии не отвечала (касаний больше нет) → база не живая.
- Честный вывод: на свежем LINK живого построения с повторными касаниями у меня пока
  НЕ НАЙДЕНО. Правильное ученическое действие — не натягивать, а искать касания;
  если построения нет — сетки нет. Этот вывод в чат уйдёт только вместе с переделанной
  разметкой, когда построение будет найдено (или с явным «не нашлося, помогите увидеть»).
- Инструмент: render_chart.py --trend (наклон по двум точкам дата:цена) — наклонный
  базис теперь рисуется, как у наставника.

## Круг 7б (06.11): наставник разметил мой LINK — эталон привязки (id 2138)
- Эталон: построение = восходящая от июльского лоу (6.996), касание цены на ней 02.11 ~10.256.
  Сетка 0=15.763 / 1=9.376 (основание построения), цена 10.6 ≈ доля 0.8.
- Моя ошибка зафиксирована: вертикальный свинг без наклона и без ответа цены — не привязка.
- Правило-алгоритм себе: 1) найти наклон, которому цена ОТВЕЧАЛА (касание+отскок); 2) привязать
  сетку вершина↔основание построения; 3) сигнал = только новое касание (цена+время).

## Критерий верной посадки (06.11, от наставника через 2194)
- «сама на 157ю встала. не сдвигал разметку» → правильная привязка НЕ требует подгонок:
  цена приходит на долю сама, сетка живёт между касаниями месяцами.
- Правило себе: если приходится сдвигать сетку под текущую цену — это палец в рану:
  привязка неверна, переделывать, а не подтаскивать.
- Практический вывод: мою круг-1 SPCX-реплику наставник держит в работе — перепроверю
  свою июльскую посадку против его сегодняшней (0≈101.5/1≈210) при следующем круге.
